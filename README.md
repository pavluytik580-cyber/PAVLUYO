# PAVLUYO MVP v4
Одна HTML-страница.

Главное:
- аватар из галереи;
- выбор 1–11 класса;
- предметы по классу;
- программа тем и уроков;
- урок → практика;
- «Соперник — Победи себя»: ошибочное задание сохраняется и повторяется без готового ответа;
- медаль «Победил себя» после исправления;
- расширенный профиль.

Каталог предметов и тем ориентирован на федеральную структуру общего образования РФ. Точный порядок тем может отличаться по школе, учебнику, профилю и региону; для 10–11 классов особенно важен профиль/индивидуальный учебный план.
